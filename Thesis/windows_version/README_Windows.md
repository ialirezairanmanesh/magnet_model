# پایان‌نامه - نسخه کامل ویندوز

این فولدر شامل تمام فایل‌های پایان‌نامه شما با تنظیمات مناسب برای ویندوز است.

## فایل‌های موجود:

### فایل‌های اصلی LaTeX:
- `SBUKThesis-main.tex` - فایل اصلی پایان‌نامه
- `SBUKThesis-commands.tex` - فایل دستورات و تنظیمات
- `SBUKThesis-persian-cover.tex` - جلد فارسی
- `SBUKThesis-english-cover.tex` - جلد انگلیسی
- `SBUKThesis-*.tex` - سایر فایل‌های پایان‌نامه
- `SBUKThesis-bibliography.bib` - فایل مراجع

### تصاویر و منابع:
- `images/` - فولدر تصاویر اصلی
- `pandoc_images/` - تصاویر پردازش شده
- `research_paper/` - فایل‌های مقاله تحقیقاتی
- `logo.png` - لوگو دانشگاه

### فایل‌های پایتون:
- `plot_*.py` - اسکریپت‌های تولید نمودار
- `requirements.txt` - پکیج‌های مورد نیاز پایتون

### فایل‌های Word:
- `*.docx` - فایل‌های Word پایان‌نامه
- `*.doc` - فایل‌های Word قدیمی

### فایل‌های PDF:
- `*.pdf` - فایل‌های PDF تولید شده

## تنظیمات اعمال شده:

1. **فونت B Zar:** برای متن فارسی
2. **فونت Times New Roman:** برای متن انگلیسی
3. **دستورات bold:** برای عناوین و متن‌های مهم
4. **تنظیمات xepersian:** برای پشتیبانی از فارسی

## نحوه کامپایل:

### روش 1: استفاده از XeLaTeX
```bash
xelatex SBUKThesis-main.tex
```

### روش 2: استفاده از اسکریپت
```bash
./compile.sh
```

### روش 3: استفاده از TeXstudio یا TeXworks
1. فایل `SBUKThesis-main.tex` را باز کنید
2. موتور کامپایل را روی XeLaTeX تنظیم کنید
3. کامپایل کنید

## نکات مهم:

- حتماً از XeLaTeX استفاده کنید (نه pdfLaTeX)
- فونت B Zar باید روی سیستم نصب باشد
- در صورت بروز خطا، فایل‌های aux را پاک کنید و دوباره کامپایل کنید

## تفاوت با نسخه لینوکس:

- در ویندوز از فونت B Zar استفاده می‌شود
- در لینوکس از فونت XB Zar استفاده می‌شود
- دستورات bold در ویندوز فعال هستند
